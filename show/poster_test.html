Adaptive MLP Pruning for Large Vision Transformers

📑Motivation

Large vision transformers achieve strong performance through increased model capacity, but their cumbersome parameters impose exorbitant computational and memory demands.

Entropy-Guided MLP Neuron Pruning Reduces Vision Transformer Complexity While Preserving Performance.
⚙Method Overview

AMP first evaluates MLP hidden-neuron importance using Taylor expansion with a label-free information entropy criterion, then ranks neurons for pruning.

  • Introduces label-free information entropy for more accurate neuron importance evaluation.
Information Entropy Improves Neuron Importance Evaluation by Exploiting All Model Predictions.
💡Key Idea
Measures Average in Formation Entropy over Model Predictions
$$ \mathcal{E} = - \frac{1}{B} \sum_{i=1}^B \sum_{j=1}^B {p_{ij} \cdot \log{p_{ij}}}. $$
Key Formula
$$ \mathcal{L}_{\rm distill} = \frac{1}{C} \Vert z^{\rm cls} - \hat{z}^{\rm cls} \Vert^2 + \frac{1}{N \cdot C} \Vert z^{\rm patch} - \hat{z}^{\rm patch} \Vert^2. $$
